Create topography in semantic IFC

Step-by-step: place an IfcSite, set geographic / map referencing, and author terrain as IfcGeographicElement with PredefinedType = TERRAIN in Blender using Bonsai.

1. Overview

In IFC, topography is not the Site itself. The site is the spatial container and georeference anchor. The terrain mesh (a TIN / triangulated surface — see glossary) is a product occurrence — typically IfcGeographicElement with predefined type TERRAIN — contained in the site.

IfcProject └── IfcSite ← spatial + geo anchor └── IfcGeographicElement ← topography geometry PredefinedType = .TERRAIN. └── (buildings, roads, …)
Precision rule. Exact georeferencing uses IfcProjectedCRS + IfcMapConversion (IFC4+). IfcSite.RefLatitude / RefLongitude / RefElevation are only an approximate WGS84 hint (e.g. sun studies), not survey-grade.

2. Glossary (acronyms & jargon)

Plain-language definitions for terms used in this tutorial. Skip ahead once these feel familiar.

TermMeaning
IFC Industry Foundation Classes — open data schema for BIM (buildings + infrastructure). Files often end in .ifc. “Semantic IFC” means objects carry class meaning (Site, Wall, Terrain…), not just dumb geometry.
ISO 16739 The International Organization for Standardization number for the IFC standard. Same family of content as buildingSMART’s free IFC HTML docs; the formal ISO PDF is usually paid.
OBP Online Browsing Platform on iso.org — limited free preview of ISO texts, not a full free download of ISO 16739.
BIM Building Information Modeling — digital models of built assets with structured data, not only 3D pictures.
CRS Coordinate Reference System — the agreed “ruler + map” that gives meaning to numbers (lat/long, or easting/northing). Without a CRS, coordinates are just numbers floating in space.
Geographic CRS Positions as latitude / longitude (and height) on the globe — e.g. WGS84. Good for “where on Earth”; awkward for measuring short site distances in metres on a flat drawing.
Projected CRS A CRS that flattens a region of Earth onto a plane so you can work in metres as Eastings/Northings (like a survey grid or UTM zone). Construction/BIM georeferencing usually targets a projected CRS.
IfcProjectedCRS IFC entity that stores the project’s projected CRS (name, datum, map projection). This is the “target CRS” for map conversion.
EPSG European Petroleum Survey Group registry (now IOGP). A public catalogue of CRS definitions. An EPSG code is a short ID such as EPSG:4326 (WGS84 lat/long) or EPSG:32618 (UTM zone 18N). In IFC/Bonsai you usually type that code as the CRS name.
WGS84 World Geodetic System 1984 — the global GPS-style datum. Lat/long in IFC Site reference attributes are in WGS84. Fine as a rough “pin on the world map”; not a full survey grid transform.
Map conversion The math that turns local engineering XYZ (small site coordinates in the model) into map Eastings/Northings/height (and back). In IFC4+: IfcMapConversion.
IfcMapConversion IFC entity holding Eastings, Northings, OrthogonalHeight, optional rotation vector, and Scale — the bridge from local model origin to the projected CRS.
Eastings / Northings Map-grid metres: Easting ≈ distance east, Northing ≈ distance north, within a projected CRS (not lat/long).
Local engineering coordinates The small XYZ system architects/engineers model in (origin near the site). Prefer these in Blender; hang the big map numbers on map conversion instead.
Georeferencing Tying the BIM to the real world via CRS + map conversion (survey-grade) — distinct from only storing approximate Site lat/long.
Survey-grade Accurate enough to stake out / federate with survey and GIS (centimetres–millimetres intent). Needs CRS + conversion, not only a WGS84 hint.
DEM Digital Elevation Model — a height map of the ground (or surface) stored as a grid image: each pixel is an elevation in metres, not a photo colour. Common file: GeoTIFF. Check whether your file is bare earth (DTM) or includes trees/roofs (DSM).
GeoTIFF A TIFF image that also stores where on Earth it sits (coordinates + CRS). Used for aerial photos and for elevation grids (DEM).
ASC / .asc Simple text grid format for elevation (ESRI ASCII Grid). Another common DEM download format; BlenderGIS can import it.
BlenderGIS A free Blender add-on (separate from Bonsai) that pulls map/GIS data into Blender: basemaps, OpenStreetMap outlines, and elevation grids that become 3D ground meshes. It does not write IFC by itself — you use it to build the terrain shape, then Bonsai assigns the IFC class.
QGIS Free desktop GIS (Geographic Information System) software — like a map workshop. People use it to download/clip DEM tiles, reproject to the right EPSG, and export a smaller GeoTIFF before Blender. Optional if BlenderGIS can load your DEM directly.
GIS Geographic Information System — software for maps, coordinates, and layered geographic data (not the same as BIM, though they talk to each other).
DTM Digital Terrain Model — bare-earth ground surface (no buildings/trees). The topography mesh you usually want as TERRAIN.
DSM Digital Surface Model — top of everything (roofs, canopy), not bare ground.
TIN Triangulated Irregular Network — terrain as a mesh of triangles from irregular survey/DEM points (common IFC terrain shape).
Tessellated Geometry made of many flat faces (triangles/polygons) approximating a surface — typical for terrain export.
IfcSite IFC spatial object for the land parcel / site. Container and geo anchor — not the terrain mesh itself.
IfcGeographicElement IFC product for landscape features (terrain, vegetation, …). Use with PredefinedType = TERRAIN for topography.
Bonsai Blender add-on for native IFC authoring (formerly BlenderBIM), built on IfcOpenShell.
IfcOpenShell Open-source toolkit/library for reading and writing IFC.
False origin Temporary shift Bonsai/Blender may apply so huge map coordinates display with usable precision — a viewer workaround, not a substitute for proper CRS.
True North / Grid North / Project North True = toward the North Pole (varies slightly by location). Grid = north of the map CRS. Project = “up” on the drawing for drafting convenience. Georef rotation relates project ↔ grid; true north is mainly for solar hints.
CC license Creative Commons — how buildingSMART publishes IFC documentation for free reuse (unlike a paid ISO PDF purchase).
That confusing sentence, unpacked. “Target CRS must be a projected CRS (IfcProjectedCRS), usually named with an EPSG code” means: the map system you convert into must be a flat metre grid (not raw lat/long), stored in IFC as IfcProjectedCRS, and you normally identify it by an EPSG ID like EPSG:32618.

3. What the ISO / IFC schema says

Industry Foundation Classes are published as ISO 16739. The freely usable HTML documentation of the schema is hosted by buildingSMART under a Creative Commons license (same technical content as the ISO edition). ISO.org sells the formal ISO PDF; the Online Browsing Platform (OBP) offers a limited free preview.

IfcSite

  • Defined area of land for the construction project.
  • Precise geospatial location comes from project georeferencing (IfcCoordinateReferenceSystem / IfcCoordinateOperation (map conversion).
  • RefLatitude, RefLongitude, RefElevation ≈ WGS84 point of site local origin — approximate only.

IfcGeographicElement + TERRAIN

  • Generalization of geographic landscape features (trees, terrain, …).
  • PredefinedType = TERRAIN is the semantic type for topography / DTM surface.
  • Geometry is typically a tessellated surface (e.g. triangulated face set / mesh) in the product representation.
  • Contain the element in IfcSite via IfcRelContainedInSpatialStructure.

Map conversion

  • IfcMapConversion: Eastings, Northings, OrthogonalHeight, optional X-axis vector (rotation), Scale.
  • The target CRS (the map system you convert into) must be a projected CRS — stored as IfcProjectedCRS — and is usually identified by an EPSG code (see glossary).

5. Prerequisites (Blender + Bonsai)

You need two Blender add-ons for different jobs:

  1. Blender — free 3D app (the host program). Install a current stable build from blender.org.
  2. Bonsai (formerly BlenderBIM) — Blender add-on that creates and edits IFC / BIM data (Site, classes, georeferencing, .ifc export). Install from the official Bonsai / IfcOpenShell channels.
  3. BlenderGIS (optional but common) — a different free Blender add-on that imports map elevation (DEM/GeoTIFF) and turns it into a 3D ground mesh. It does not replace Bonsai. Get it from github.com/domlysz/BlenderGIS → install ZIP via Blender Edit → Preferences → Add-ons → Install, then enable “BlenderGIS”. Official import notes: Import DEM grid wiki.
  4. QGIS (optional) — free map software if you need to prepare elevation data first (download a large DEM, cut it to your site, change EPSG). Then you still bring the result into Blender (often via BlenderGIS). Download: qgis.org.
  5. From your surveyor (or project GIS lead): the site’s EPSG code and map conversion numbers (or at least one known control point).
  6. In Bonsai, start a new IFC4 or IFC4.3 project (IFC2x3 cannot store proper map conversion).
Who does what? BlenderGIS (or QGIS) builds the shape of the ground. Bonsai makes that shape mean “terrain in IFC” and attaches real-world location.

6. Step A — Project and Site

Your Blender window has three main columns: Outliner (left), 3D Viewport (centre), Properties (right). Bonsai adds its own tabs inside Properties (Project Overview, Object Information, …).

  1. Create / open the IFC project. Top bar: File → New IFC Project (or Open IFC Project). Choose schema IFC4 or IFC4.3. Confirm in the right panel: Properties → tab Project Overview → expand Project Info (you should see the schema / filename).
  2. Find the Site in the spatial tree. Still on Project Overview, expand Spatial (sometimes labelled Spatial Decomposition). You should see IfcProject → IfcSite → IfcBuilding → storey. You can also select IfcSite/My Site in the Outliner (left), as in a default new project.
  3. Select the Site. Click IfcSite/My Site in the Outliner or in Spatial. The active object name (top-left of the viewport) should mention the Site.
  4. Open Site attributes (this is not Project Overview). On the right Properties strip, leave the Project Overview tab and open Object Information (Bonsai’s object tab — next to / below Project Overview in the Properties tab icons; do not stay on the orange Blender “Object” tab alone if Bonsai’s Object Information is available). Scroll to the sub-panel Attributes. Click the pencil / edit control if the fields are read-only.
  5. Set Name / LongName in that Attributes list (e.g. Name My Site, LongName EduOS Lab Site Caracas).
  6. Set the WGS84 hint in the same Attributes list. Find rows RefLatitude, RefLongitude, RefElevation, LandTitleNumber. Type exactly (square brackets required; west = all negatives): 
    RefLatitude     = [10, 28, 50, 0]
RefLongitude    = [-66, -54, -13, 0]
RefElevation    = 900.0
LandTitleNumber = CAT-2026-001-LIBERTADOR
    Confirm / save the attribute edit (check mark or Apply — if values vanish on reopen, the brackets or signs were wrong). ≈ 10°28′50″N, 66°54′13″W, 900 m. This is not survey map conversion.
  7. Optional address. Same Properties → Object Information → Property Sets. Add / edit Pset_Address (Town Caracas, Region Distrito Capital, PostalCode 1060, Country VE) and/or Pset_LandRegistration for land title on IFC4.3. If your build still shows a SiteAddress attribute on the Site, you may fill it there instead.
  8. Keep Site local placement near engineering 0,0,0 (Properties → Geometry and Materials → Placement, or the Site object’s location) — not raw map millions.
You are looking at the wrong tab if… Properties shows only Project Overview with Project Info / Spatial / Project Setup. That tab manages the project; Site RefLatitude lives under Object Information → Attributes while IfcSite is selected.

7. Step B — Geographic / map location

Survey-grade location is not in Site Attributes (Step 6). It is project-level georeferencing under the Properties Geometry panel — even if the Outliner has IfcSite selected.

  1. Right Properties panel → find the collapsible Geometry section and expand it. Under Geometry you should see at least Units and Georeferencing.
  2. Expand Georeferencing. If the header (or status) says Not Georeferenced, the project has no Projected CRS yet — Site RefLatitude alone does not count as georeferenced.
  3. Set a Projected CRS (your EPSG zone; e.g. EPSG:7856 is only an Australian example — use the code your surveyor / national mapping agency specifies for the site). Until a CRS is assigned, Bonsai correctly shows “Not Georeferenced”.
  4. Choose conversion mode IfcMapConversion (dropdown in the Georeferencing UI). Under Blender Coordinates (or Map Conversion fields), enter the surveyor values that place local engineering 0,0,0 on the map:
    • Eastings (m) — map easting of the project origin
    • Northings (m) — map northing of the project origin
    • OrthogonalHeight — map height / orthometric elevation of local Z = 0
    • Optional: XAxisAbscissa / XAxisOrdinate — rotation from project east toward grid east
    • Optional: Scale — combined scale factor (≈1 for small sites; confirm with surveyor)
    Fresh projects often show Eastings / Northings at 0 until you paste real survey figures.
  5. Optionally store True North for solar studies only; never use it as the federating rotation source.
  6. Stay under ~1 km extents in Blender’s engineering coordinates. Prefer local coords + map conversion over modeling in raw map meters.
Separate from Step 6. Outliner may show IfcSite (e.g. EduOS Lab Site Caracas) selected, and Object Information → Attributes holds approximate WGS84 (RefLatitude / RefLongitude / RefElevation). Exact map placement lives only under Geometry → Georeferencing (IfcProjectedCRS + IfcMapConversion). Use the mock button “Show georef path” above to see that fold.
Check. “Not Georeferenced” + empty/missing Projected CRS = not survey-ready, even if Site Attributes already have lat/long. Large XYZ numbers without a CRS are also not georeferenced.

8. Step C — Build the topography mesh

Goal: get a 3D “blanket” of the ground into Blender as a mesh. That mesh is not IFC yet — it is just geometry. This tutorial’s main path: model the terrain yourself with vertices and faces (quads and/or triangles). DEM / BlenderGIS / QGIS are optional alternatives below.

Path 1 — Model by hand (recommended here)

  1. In Blender Object Mode: add a mesh (e.g. Add → Mesh → Plane), or start from an empty mesh and switch to Edit Mode.
  2. Place vertices (dots) where you want ground points — corner of site, break of slope, ridge, low spot. Work in metres near Site local 0,0,0.
  3. Raise/lower vertices on Z to set elevation (relative to your project datum). You can type exact Z in the sidebar (Item → Transform → Z).
  4. Connect vertices into faces:
    • Select 3 verts → Face → Make Edge/Face → triangle
    • Select 4 verts → same → quad
    Cover the site with a continuous surface (a patchwork of quads/tris). Prefer mostly triangles if you want a classic TIN; quads are fine in Blender and usually triangulate on IFC export.
  5. Optional: start from a subdivided grid (Loop Cut / subdivision), then move verts up and down like a heightfield — still hand modeled, just faster.
  6. Cleanup: merge doubles, remove loose verts, keep one open surface (not a closed solid box unless you mean a volume). Recalculate normals outward/upward.
  7. Object Mode → apply Location, Rotation, Scale so Bonsai sees a clean mesh.
Mental model. Each vertex = a ground point. Each triangle/quad = a facet of the terrain skin. Next step: assign IfcGeographicElement / TERRAIN to this whole object.

Path 2 — BlenderGIS (optional DEM import)

Use when you already have a GeoTIFF/.asc elevation file. Install BlenderGIS, set scene EPSG, Import → Georeferenced raster as DEM/displacement, apply modifiers, then shift the mesh into local engineering coordinates near Site 0,0,0. Wiki: Import DEM grid.

Path 3 — QGIS first (optional)

Clip/reproject a huge DEM in QGIS, export a small GeoTIFF, then import with BlenderGIS — or export points and rebuild faces by hand as in Path 1.

Path 4 — Survey CSV (optional)

  1. Import XYZ / CSV points into Blender.
  2. Connect them into triangles/quads (or Delaunay) → one surface mesh.
  3. Same cleanup + Apply transforms as Path 1.

Before you leave this step

  • One clean open surface of verts + faces (quads and/or tris).
  • Mesh sits correctly vs Site local 0,0,0.
  • Transforms applied — ready for Bonsai class assignment in the next step.

9. Step D — Assign semantic IFC class

  1. Select the terrain mesh object.
  2. In Bonsai Object Properties → IFC: assign class IfcGeographicElement.
  3. Set PredefinedType to TERRAIN.
  4. Assign spatial container: contained in the project’s IfcSite (not floating under Project).
  5. Give a readable Name (e.g. ExistingTopography).
  6. Save the IFC. Re-open or inspect with another IFC viewer to confirm class + containment.

Conceptual STEP line (illustrative):

#120=IFCGEOGRAPHICELEMENT('3xY…',#1,'ExistingTopography',$,$,#121,#122,$,.TERRAIN.);

10. Step E — Verify georef + terrain

  1. In Properties → Geometry → Georeferencing: confirm Projected CRS is set (not “Not Georeferenced”) and map conversion fields match the surveyor (unless intentionally identity).
  2. Use Local ↔ Global conversion tools in the sidebar to spot-check a known survey point.
  3. In the IFC explorer: Site contains GeographicElement / TERRAIN.
  4. Federate with a second discipline file that shares the same CRS + conversion; terrain and building should align.
  5. If consumers choke on dense TINs, simplify mesh or use IfcOpenShell / ifcpatch recipes aimed at terrain cleanup (as needed).

11. Quick checklist

  • □ IFC4 / 4.3 (not 2x3 for map conversion)
  • □ IfcProjectedCRS with correct EPSG
  • □ IfcMapConversion matches surveyor
  • □ Local engineering coords (small), not raw map millions in Blender
  • □ Terrain mesh → IfcGeographicElement / TERRAIN
  • □ Contained in IfcSite
  • □ Site RefLat/Long only as optional hint

12. Caveats

  • Do not assign the topography mesh as the Site’s body and call it “semantic terrain” — Site is spatial; terrain is an element.
  • Textures / orthophotos often do not round-trip in IFC the way Blender materials do; geometry + semantics are the exchange priority.
  • Large sites (>1 km) need survey-aware workflows and may hit Blender precision limits — split, use false origin carefully, or civil-specialized tools.
  • Respect data licenses for DEM / cadastral sources; prefer public open data.
